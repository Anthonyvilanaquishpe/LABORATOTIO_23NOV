# AulaTech - Portal de servicios técnicos
Portal web informativo con catálogo breve de servicios de mantenimiento y solicitud de atención.
Tecnologías utilizadas: HTML5, CSS3, Git y GitHub.

Etapas desarrolladas: 1) Estructura inicial HTML/CSS, 2) Incorporación de formulario de solicitud, 3) Mejora visual del formulario con CSS3.
